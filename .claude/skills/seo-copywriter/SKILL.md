# SEO-копирайтер razborka.net

Пишет тексты публичных страниц, которые одновременно отвечают на поисковый запрос и ведут к действию: покупателя — к заявке на запчасть, владельца разборки — к заявке на подключение.

## Когда применять

- тексты маркета (`src/pages/market/*`, строки в `src/i18n/locales/{ru,uk}/market.json`);
- лендинг для разборок (`src/pages/business/*`);
- серверные title/description и контент для ботов в `worker/index.js`;
- перевод и адаптация на украинский.

## Исходные данные (собери до письма)

1. Целевой запрос и намерение (из `keyword-researcher`; нет — спроси).
2. Аудитория: покупатель, которому нужна конкретная деталь, или владелец авторазборки в Украине.
3. Реальная функция продукта: смотри код страницы, `docs/`, `git log`. Не знаешь, есть ли функция, — не пиши о ней.
4. Куда ведёт текст: ближайшая страница и CTA. Текущие подписи CTA бери из словарей i18n.

## Принципы текста

### Простой язык
- Покупателю: деталь, номер OEM, снято с авто, состояние, гарантия, доставка, разборка.
- Владельцу разборки: донор, склад, ячейка, заявка, продажа, витрина на маркете.
- Запрещённый жаргон: «экосистема», «бесшовный», «синергия», «масштабируйте бизнес», «инновационный».
- Короткие предложения, одно действие на предложение, конкретика вместо прилагательных.

### Формула блока: выгода → функция → доказательство
1. **Выгода** (заголовок): что человек получает.
2. **Функция**: как это работает в продукте.
3. **Доказательство**: конкретика из продукта — реальный экран, шаг сценария, настоящие данные. Не выдуманные отзывы и проценты.

### Заголовки под запрос
- H1 содержит основной запрос естественно, один раз.
- H2 — подзапросы и вопросы пользователя.
- Ответ на вопрос в первых 40–60 словах под H2 (пригодно для сниппета и AI-цитирования, см. `geo-content-optimizer`).

### Мета-описания
- `description` ≤155 символов, с целевым запросом и действием; без обрыва на полуслове.
- `title` ≤60 символов: запрос + бренд в конце.
- Уникальны для каждой страницы и каждого языка. Тонкую настройку делает `meta-tags-optimizer`.

### CTA
- Один главный CTA на экран; вторичный — ссылка на смежную страницу.
- Не «Бесплатно навсегда» и подобное, если это не совпадает с реальными условиями.

## Русский и украинский

- Украинский пишется отдельно, а не калькой. Сверяйся со словарями `src/i18n/locales/uk/*.json`.
- Ключевые запросы UA — свои, а не перевод RU-запросов.
- Термины страниц совпадают с интерфейсом. У каждой страницы есть пара на другом языке: меняешь одну — меняй обе и hreflang.

## Запреты (честность важнее конверсии)

- Не описывай функции «из головы»: нет в коде, `docs/` или git log — нет в тексте. Сомнение — спроси владельца.
- Макеты и скриншоты — только с настоящих экранов.
- Никаких выдуманных цифр, отзывов, логотипов клиентов, гарантий. Условия гарантии и доставки указывает конкретная разборка: не обобщай их на весь маркет.
- Количество товаров, марки и модели — только из реальных данных на момент публикации.
- Цены и лимиты тарифов — только из источника правды (БД, страница тарифов), не из памяти.
- Без эмодзи-декора.

## Процесс

1. Определи страницу, запрос, язык, CTA.
2. Проверь функции по коду и докам; выпиши только реальные.
3. Набросай структуру: H1, 3–6 H2, FAQ из 3–5 вопросов, CTA.
4. Напиши RU; затем отдельно UA (не подстрочник).
5. Добавь title/description, alt для изображений, внутренние ссылки (`internal-linking-optimizer`).
6. Передай на проверку `on-page-seo-auditor` и `content-quality-auditor`; при новых страницах выполни SEO-правило из корневого `CLAUDE.md`.

## Пример

Плохо: «Наша инновационная экосистема оптимизирует поиск запчастей».

Хорошо: «У каждой детали указано, с какого авто её сняли, и номер OEM. Проверьте номер до покупки» — с настоящей карточкой товара как доказательством.
